=== Hermes Agent 基础操作 — 安装与初始配置 ===

== 1. 安装 ==

Hermes Agent 目前只提供一键安装脚本，无 pip 或 Homebrew 渠道：

curl -fsSL https://raw.githubusercontent.com/NousResearch/hermes-agent/main/scripts/install.sh | bash

安装完成后自动创建以下目录结构：
  ~/.hermes/config.yaml       # 主配置文件（YAML 格式）
  ~/.hermes/.env              # API Key 和密钥
  ~/.hermes/skills/           # 已安装的技能
  ~/.hermes/sessions/         # 对话记录（SQLite）
  ~/.hermes/logs/             # 网关和错误日志
  ~/.hermes/auth.json         # OAuth Token 和凭证池

== 2. 验证安装 ==

hermes doctor           # 检查依赖和配置完整性，--fix 自动修复可修复项
hermes --version        # 查看版本号

常见问题：
  - 如果报 "command not found"，确保 ~/.local/bin 在 PATH 中
  - 如果 Python 版本过低，需要 Python 3.11+

== 3. 首次配置 ==

交互式配置向导（推荐）：

hermes setup            # 进入交互配置，按顺序设置 model → terminal → gateway → tools → agent

分段配置：
hermes setup model      # 只配模型/供应商
hermes setup terminal   # 只配终端后端（local/docker/ssh/modal）
hermes setup gateway    # 只配消息平台
hermes setup tools      # 只配工具集
hermes setup agent      # 只配 Agent 行为参数

== 4. 模型/供应商配置 ==

hermes model            # 交互式选择模型和供应商

支持 18 个供应商，常用：
  供应商          | 认证方式        | 环境变量
  OpenRouter      | API Key         | OPENROUTER_API_KEY
  Anthropic       | API Key         | ANTHROPIC_API_KEY
  DeepSeek        | API Key         | DEEPSEEK_API_KEY
  OpenAI Codex    | OAuth           | hermes login --provider openai-codex
  GitHub Copilot  | Token           | COPILOT_GITHUB_TOKEN
  自定义端点      | 配置文件         | config.yaml 中设置 model.base_url + model.api_key

示例自定义供应商配置（直接修改 config.yaml）：

model:
  provider: custom
  model: deepseek-chat
  base_url: https://api.deepseek.com/v1
  api_key: ${DEEPSEEK_API_KEY}

环境变量文件 ~/.hermes/.env 示例：

OPENROUTER_API_KEY=sk-or-v1-xxxxx
ANTHROPIC_API_KEY=sk-ant-xxxxx
DEEPSEEK_API_KEY=sk-xxxxx

== 5. 凭证池（Credential Pool）===

当你有多个同供应商 API Key 时，可以加入凭证池自动轮换：

hermes auth add              # 交互式添加凭证
hermes auth list openrouter  # 查看 OpenRouter 下的所有凭证
hermes auth remove openrouter 1  # 移除第 1 个

凭证池自动轮换——如果一个 Key 达到速率限制或配额耗尽，自动切换到下一个，无需手动干预。

== 6. 快速启动 ==

hermes                      # 进入交互式对话（默认模式）
hermes chat -q "你好"       # 单次查询，非交互模式
hermes chat -q "列出当前目录文件" --yolo  # 跳过危险命令确认（单次授权）

常用启动参数：
  -q, --query TEXT          # 单次查询，适合脚本调用
  -m, --model MODEL         # 临时切换模型
  -t, --toolsets LIST       # 限制使用的工具集
  --provider PROVIDER       # 强制使用某个供应商
  --yolo                    # 跳过危险命令审批
  -v, --verbose             # 详细输出

== 7. 配置管理 ==

hermes config               # 查看当前配置
hermes config edit          # 用编辑器打开 config.yaml
hermes config set agent.max_turns 120  # 设置最大对话轮数
hermes config path          # 打印 config.yaml 路径
hermes config env-path      # 打印 .env 路径
hermes config check         # 检查配置是否有遗漏/过期
hermes config migrate       # 更新配置为新版本格式

关键配置项速查：

  配置路径                            | 作用                        | 默认值
  model.default                       | 默认模型名称                | （取决于首选供应商）
  model.provider                      | 默认供应商                  | openrouter
  agent.max_turns                     | 单次对话最大轮数            | 90
  terminal.backend                    | 终端后端（local/docker/ssh）| local
  terminal.timeout                    | 命令超时秒数                | 180
  compression.enabled                 | 上下文压缩开关              | true
  compression.threshold               | 触发压缩的上下文占用比例     | 0.50
  display.show_cost                   | 是否显示 token 费用         | false
  security.tirith_enabled             | 安全策略引擎开关             | true
  memory.memory_enabled               | 跨会话记忆开关               | true
  delegation.model                    | 子任务委托模型              | （同主模型）
  checkpoints.enabled                 | 文件系统检查点开关           | false

完
