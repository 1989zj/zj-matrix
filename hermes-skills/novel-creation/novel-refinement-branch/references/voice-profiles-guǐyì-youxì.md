# Character Voice Profiles — 诡异游戏：我的规则别人看不见

> 实测提升：对话声音重塑 25 条修改 → Character Charm +0.63（6.7→7.33）
> 应用章节：ch4-9（6章，15,890字）

## 林远（男主，24岁，能看到规则文本）

**角色定位**：规则视觉者，地质背景，能「看到」墙上空气中的规则文字。

**说话特征**：
- 短句、直接、果断——句尾少语气词（啊/呢/吧），多名词+句号收尾
- 非必要不使用「好像/可能/大概」
- 观察驱动的叙述跳跃，常直接说结论而非过程
- 压力下更简短，几乎变成单字

**改写前**（太啰嗦/普通）：
- 「你能看到规则文本？」 → 「规则文本？」
- 「活板门上的那行字——内容是什么？」 → 「那行字。内容。」
- 「你怎么不早说？」 → 「你刚找到的？」
- 「你为什么不自己去开？」 → 「你自己不开？」

**改写后示例**：
- 「一起进。」（原句「那一起进。」）
- 「十扇门，十种语气。像是他们最后时刻留下的话。」（原句删去「住在这些房间里的人，在最后的时刻，写下了各自最重要的一句话」中的冗余）

## 陈远志（前设施研究员，40+岁，能感觉到规则温度）

**角色定位**：B-7 设施前研究人员，规则温度感应者。被关在设施中多年，知道太多。

**说话特征**：
- 语气沉稳但透着疲惫——每句话都带着「说清楚但不想多说」的矛盾感
- 用语精确但啰嗦（像是/可能/换句话说），像在用旧时代的报告口吻
- 句子里带有停顿感（破折号、省略号使用频率高）
- 情绪波动极少，即便是危险时刻也用分析性语气

**改写方向**：保留分析性但增加疲惫感——适当缩短句长，删去过度解释性的「换句话说」「也就是说」。

## 刘闯（工厂工人，30岁左右，务实）

**角色定位**：打工人，体力型角色，行动派。

**说话特征**：
- 短句为主，口语化，带行业用语（东西/事/搞）
- 语速快，不耐烦时用「啧」「不是」打断
- 用词接地气，不用书面词
- 情绪直接挂在脸上——高兴就「行」，不爽就「扯淡」

**改写前**（太规整）：
- 「需要卡。」（附带动作描述） → 「啧，得刷卡。」

**改写方向**：增加「啧」「操」「搞」「整」等口语词，句子缩短，不用「然而」「因此」等连词。

## 赵铁（退伍军人，50+岁，在设施独活了两个月）

**角色定位**：前军人，在 B-7-A-01 独活两月，用手法钻规则空子。

**说话特征**：
- 说话像汇报——短、准、不带感情色彩
- 偶尔冒出黑色幽默（语气平淡地说荒谬的话）
- 每句话都是一条信息——不浪费字
- 用身体经验说话（「我试过……」），而非推理

**改写前**（太普通）：
- 「你们——也是活人？」 → 「活的？」
- 「要去看看吗？」 → 「去看看？」

**改写方向**：句子极端简短，像军事汇报。去掉复句结构。陈述事实而非表达判断。

## 方晴（地质研究生，25岁）

**角色定位**：科班地质背景，学术思维，同为规则感知者（但只看到轮廓/情绪）。

**说话特征**：
- 提问驱动——总是在排查，总是在问问题
- 语气里带着学术思维的痕迹（严谨但紧张）——「这不对」「从理论上说」
- 压力大时用问题掩饰不安
- 推眼镜是标志性动作（角色固有习惯）

**改写前**（叙述性过强）：
- 「我刚才在观测室的地板下面发现了一个活板门。」 → 「观测室地板下面有个活板门。」
- 「这不对。地下设施的楼梯间，应该有通风管道和排水系统。」 → 保留但增加停顿节奏

**改写方向**：长解释性句子改为短陈述+问题的组合。保留学术用词但增加紧张感导致的断裂。

## 顾晚（护士助理，能感觉到规则热量）

**角色定位**：规则温度感应者。冷静、直觉型。话少但准确。

**说话特征**：
- 话少但准确——每句话要么是发现，要么是确认
- 语气平静，情绪起伏不明显
- 说结论时用确认语调而非疑问
- 赤着脚——这个身体细节本身就是她的「听诊器」

**改写前**（改问句为陈述）：
- 「你看到了？」 → 「你看到了。」（改问号为句号——她说结论而非提问）
- 「这个房间的设计不是为了关人，它是为了测试。」 → 「不是关人——是测试。」

**改写方向**：删除冗余主语和连词，直接说结论。疑问句改陈述句（她有答案，不需要问）。用破折号串联两个因果。

## 通用规则

1. 所有角色对话中，「好像/仿佛/似乎/看起来」等 AI 敏感词必须删减 50%+
2. 过度解释是最大的敌人——角色对话不应有「逻辑链条完整」的感觉
3. 角色对话差异的核心在于：**句长、用词等级、信息密度、情绪表现方式**
4. 永远不要为了节奏压缩角色专属的说话细节
