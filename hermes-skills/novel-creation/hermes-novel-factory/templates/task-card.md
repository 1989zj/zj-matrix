# 任务卡模板

```
卡片名：
负责人：
目标：
输入：
输出：
依赖：
验收标准：
状态：🟡 Backlog | 🔵 进行中 | 🟢 已完成 | 🔴 阻塞
备注：
```

## 字段说明

| 字段 | 说明 |
|------|------|
| 卡片名 | 简洁描述任务，如《设定#1 主角人设卡》《正文#3 第5-7章》 |
| 负责人 | 执行的 profile 名 + 具体子任务 |
| 目标 | 一句话说明本次任务要达成什么 |
| 输入 | 依赖的上游产出物，如大纲文档路径、人设卡 |
| 输出 | 本任务产出的文件/内容路径 |
| 依赖 | 前置任务卡片名，多个用逗号分隔 |
| 验收标准 | 可量化的完成标准 |
| 状态 | 🟡 Backlog / 🔵 进行中 / 🟢 已完成 / 🔴 阻塞 |
| 备注 | 风险提示、待确认事项、特殊要求 |

## 看板列

```
Backlog → Researching → Outline Ready → Character Ready → Drafting → Editing → Compliance Check → Ready To Publish → Published → Archived
```
