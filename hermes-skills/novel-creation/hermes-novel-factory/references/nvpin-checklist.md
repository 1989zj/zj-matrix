# 女频网文写作检查清单

## 适用场景
重生虐恋、嫡女复仇、宫斗宅斗、双强CP、打脸爽文（女频向）

## 与男频的核心差异

| 维度 | 男频 | 女频 |
|------|------|------|
| 核心驱动力 | 升级、力量、征服 | 情感、关系、成长 |
| 主角弧光 | 从弱变强 | 从被骗到觉醒 |
| 爽点来源 | 打脸、碾压、收小弟 | 复仇、反转、被珍视 |
| 感情线 | 可有可无 | 必须完整（至少支线） |
| 结局 | 开放/继续升级 | 必须HE（happy ending） |
| 读者期待 | 爽就完事 | 爽+感动+解气 |
| 配角作用 | 经验包/垫脚石 | 推动情感/制造误会 |

## 女频常见结构模板

### 重生虐恋模板（25章版实测有效）
- Ch1-3: 前世惨死→重生觉醒→第一轮打脸（黄金开局）
- Ch4-10: 庶妹/白莲花线展开、布局反杀、渣男动摇
- Ch11-15: 暗桩浮出、身世/身份揭秘、局势升级
- Ch16-20: 最大危机（宫变/家族覆灭危机）、高潮爆发
- Ch21-25: 渣男结局→感情HE→暗线收束→大结局

### 关键节奏点
- 第3章末：必须有第一次爽感反馈
- 第10章：不能拖，至少解决第一个副线
- 第15章：必须有剧情反转或大事件
- 第19章左右：情感转折点（单独写，不宜并行）
- 第25章：必须HE，但可以留一丝回味

## 女频编辑专查项（P0级常见问题）

| 问题 | 实战案例 | 修复方法 |
|------|----------|----------|
| **父亲名字写错** | 沈镇山 → 沈怀远（第14章发现） | editor全局搜索替换 |
| **庶妹名字写错** | 沈明珠 → 沈婉婷（第25章发现） | editor全局搜索替换 |
| **排行不一致** | 三小姐/五小姐 → 统一为二小姐 | 确认character.md中的排行后统一 |
| **妾室姓氏混用** | 周姨娘/孙姨娘 → 统一为柳姨娘 | editor全局搜索所有姨娘名 |
| **"女主"占位符** | 正文出现"女主咬牙切齿" | 替换为"沈云锦咬牙切齿" |
| **关键道具不一致** | 手帕绣字内容前后矛盾 | 查阅最早出现章节确认描述 |
| **场景跳跃** | 批次间无过渡，地点突变 | 补充1-2句场景过渡 |

## 女频写作规则

### 人称统一
- 女主视角：用全名（"沈云锦"），不简化为"锦儿"除非在亲密场景
- 渣男视角：用全名或"他"，避免过度美化
- 第三人称有限视角：每章固定一个POV人物

### 感情线节奏
- 前期（Ch1-10）：渣男伤害值拉满，女主冷漠复仇
- 中期（Ch11-18）：渣男逐渐动摇，女主不为所动
- 转折（Ch19左右）：一个让女主看到渣男另一面的事件
- 后期（Ch20-25）：真相大白、放下、HE

### 对话比例建议
- 女频读者看重对话和内心独白
- 建议对话占比40-50%，内心戏15-20%，叙述30-40%
- 对话要带情感标签（"她冷笑"、"他低声道"），不只是"她说"

### 常见女频雷区
- 女主太弱/太圣母 — 重生后须立即展现成长
- 渣男洗白太突然 — 需要足够铺垫和剧情事件
- 姐妹们智商不在线 — "智斗"需要双方都有智力交锋
- 关键时刻不解决 — 女主安排的计划必须执行并看到结果
- 情感转折生硬 — 恨到爱需要合理解释
