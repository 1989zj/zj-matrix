# 入宫面见贵妃/皇后 — 深宫审问与脱身模板

**适用场景**：女频重生文中，女主被召入宫中面见高位后宫（贵妃/皇后/太后），对方已起疑心，通过层层话术试探。女主需在表面恭谨下巧妙周旋，最终仰仗外力（通常是男主的突然到访）脱身。结尾通常有秘密传信作为钩子。

## 三度试探标准结构（以2000-2100字章节为例）

| 时序 | 内容 | 预估字数 |
|------|------|----------|
| ① 入宫触发 | 马车/小轿入宫，路过前世死亡地点（朱雀门/宫道/台阶），握拳压恨意 | ~150 |
| ② 高位登场 | 贵妃/皇后的宫殿描写（椒房殿/坤宁宫），外表慈祥的描述+"可她知道下面藏着什么"的前世对照 | ~250 |
| ③ 第一探：身世软肋 | 对方提母亲/家世/亡故亲人——下马威+试探底细。女主不卑不亢回击，暗讽对方上了年纪/过时。 | ~300 |
| ④ 第二探：具体事件 | 对方提一件具体可疑事件（金面绣娘/百鸟朝凤图/可疑诗句），追问细节。女主否认+推给第三人。 | ~350 |
| ⑤ 第三探：直接怀疑 | 对方直接抛出推测（"那绣娘身形与你相似"），逼近核心秘密。女主用自嘲/示弱化解。气氛紧绷到极点。 | ~400 |

| ⑦ 密信钩子 | 退场后，小太监/宫女偷偷塞纸条，男主警告/示好。女主销毁证据（扔荷花池/烧掉/吞下），心中暗下决心。 | ~300 |

## 技法要点

### 1. 三探递进逻辑

三个阶段的话术要越来越尖锐：

- **第一探**（表面寒暄实则打压）：用"怀旧"的语气揭伤疤。"那年你还小，跟在你母亲身边，怯生生不敢说话"——表面温情，实则提醒对方「你没妈撑腰」。
- **第二探**（具体证据追查）：抛出她知道确切存在的东西（某幅绣品、某首诗、某次可疑行踪）。女主必须完全否认或推给别人，不能露出"知道太多"的破绽。
- **第三探**（直接指控）：将前两轮线索拼在一起，做出有依据的猜想（"那绣娘身形与你相似"）。女主最危险的一关——任何多余解释都会加重嫌疑，最佳策略是自嘲/示弱/用更大的日常琐事稀释严肃性。

### 2. 高位反派的塑造

贵妃/皇后不能是脸谱化的毒妇。写作要点：

- **外貌**：温婉、慈祥、保养得宜。"嘴角噙着恰到好处的笑意"——让人看了觉得这是个好说话的人。
- **话术**：用软刀子。"说起来……""本宫倒是好奇……""本宫听说……"——用语气词和省略号制造表面随意实则步步紧逼的效果。
- **动作**：漫不经心的小动作（拨弄玉镯、端茶抿一口）——表示她游刃有余，不把对方放在眼里。
- **变化**：当男救场出现时，"眼底的笑意微微一滞"——一个微表情的变化表明对方被打乱了节奏，但不继续写，留给读者去品。

### 3. 女主的应对策略

- **被提身世软肋**：不要落泪或愤怒。用"恭维"回击——夸对方记性好，实则讽刺她上了年纪。表面完美恭敬，内里有刺，让对方噎住。
- **被问具体事件**：推给第三人（"绣娘献完礼便走了，臣女未曾多问"）。最简洁的回答，不加多余解释——任何多余解释都是破绽。
- **被直接怀疑**：用自嘲/示弱化解（"臣女若会那等手艺，早给祖母绣寿礼了"）。把严肃指控变成日常小事，四两拨千斤。同时保持表情坦然，目光清澈。

### 4. 男主救场的技巧

- **借口要合理**：顺道路过、送东西（墨兰）、请安——不能太刻意。
- **演技要到位**：男主目光扫过女主时不能有任何停顿或异常，"就像在看一件再寻常不过的陈设"。
- **目的要双重**：表面来见贵妃（送花/请安），实际来打断审问。说的话滴水不漏，既解释了来意，又不显得刻意。
- **出场节奏**：必须在第三探气氛绷到极点时登场——"话音刚落，门外太监尖嗓传来"。时机精确如舞台剧。

### 5. 密信接头的处理

- **传信人选择**：小太监/小宫女——身份低微不易被注意到、可快速消失在回廊拐角。
- **交接方式**：以"捡到手帕"为掩护塞纸条，不直接喊名字或使眼色。
- **纸条内容**：一句话足矣。警告/安排/示好。笔迹成为情感链接——"她一眼便认出那是他的字"。
- **销毁**：当场销毁不留下证据——扔荷花池（水毁）、撕碎冲茅厕、吞下。动作要自然（"经过荷花池时随手扔出"）。

### 6. 注意事项（陷阱）

- **不要在宫殿内展示女主的高情商**。在贵妃面前，女主应当被压着打——只能勉强应对，不能反杀。深宫不是宅斗，贵妃/皇后是最高层，女主现阶段完全没有翻盘能力。反杀发生在后续章节（出宫后布局）。
- **男主不能和女主有互动**。任何眼神交流、微表情交换都会被贵妃看在眼里。"两人没有任何眼神交流，甚至连衣角都没有碰到。"——这才是安全的。
- **贵妃的疑虑要保留**：男主登场后贵妃虽然被迫放人，但心中疑虑未消——她只是暂时被打断，不是被说服。女主的处境反而更危险了（因为贵妃确认了"有古怪"）。这不是胜利，是延迟了危险。
- **字数大头在对话**：这种章节90%的篇幅是对话+内在心理活动，纯粹的叙述/描写不超过10%。对话每回合要紧凑，不拖泥带水。
- **不要写太多内心独白**：女主内心OS控制在每轮试探后1-2句。写太多会破坏节奏，让读者觉得女主一直知道答案所以不紧张。
