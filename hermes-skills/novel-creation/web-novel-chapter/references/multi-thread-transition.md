# 女频重生 — 旧人新事·多线收束篇

## 适用场景

小说进入中后期，多条旧线需要收束/推进，同时引入新威胁。本质上是一个"清空棋盘"的过渡章——每条旧线给一个短场景，感情线给一个安静节拍，最后用全新钩子收尾。

**特征词判断**：如果用户给出的章节结构包含"庶妹来信+顾璟离京+深夜来客"或类似的多线并行描述，直接使用本模板。

## 七拍模板

| 拍 | 内容 | 估算字数 |
|----|------|---------|
| ① 新常态开场 | 生活看似步入正轨（婚事定/绣庄火），幽默调剂 | ~150字 |
| ② 旧线·旧敌示弱 | 旧敌来信/托人假装悔过，女主识破并反制 | ~250字 |
| ③ 旧线验证 | 监视印证旧敌暗中联络新势力（三皇子残党等） | ~200字 |
| ④ 旧线·配角退场 | 配角完成人物弧线后离开（守墓/远行/赎罪） | ~300字 |
| ⑤ 旧线收尾·感情确认 | 女主将线索/名单交给男主，行动代替告白 | ~250字 |
| ⑥ 新线钩子·深夜来客 | 神秘人携关键物品出现，暗示更深层的威胁 | ~400字 |
| ⑦ 主题句收束 | 一句点题，"她以为一切都结束了，可原来故事才刚刚开始" | ~100字 |

骨架总字数：约1650-1750字。润色加描写后自标2000-2100字。

## 风格规则

- **每个旧线场景仅2-3个对话/动作**，不要展开描写——这是过渡章，不是高潮章
- **意象统一**：用一个贯穿意象（灯火/书信/针线）串联所有场景
- **感情确认用行动而非语言**——递名单时的眼神、握手的温度，比一句告白更有力
- **新线钩子必须承载下一章的剧情爆发点**——不是"有个人来了"，而是"这个人带来的东西暗示了更大的阴谋"
- **主题句收束不宜太长**——一句即可

## 裁剪技巧（防超标）

- **猫项圈式风俗描写是最容易压缩的段落**——有气氛价值但不推进剧情
- **旧线验证段（周伯来报）天然紧凑，不宜再砍**——这是信息密度最高的部分
- **配角退场段的内心独白最容易超标**——顾璟的"最后一份人情"一句之内完成就够了

- **Session 2026-05-13 (第23章)**: 初稿2523字（目标2000-2100）→ 3次裁剪到2080字。超标21%。
- 氛围段（猫项圈趣事）是第一次裁剪的目标——砍掉35%的描述性文字，剧情完整度零损失。
