# 毒计察觉篇 — 女频重生 设毒 → 察觉 → 查毒 → 伏笔 章节结构

## 适用场景

庶妹/继母/侧室通过孙嬷嬷等心腹在茶饮中下慢性毒（"慢性子"类），女主前世喝过此毒，今生一口察觉。情节核心不在"当场打脸"而在"察觉 → 溯源 → 反击预备"的过程推进。

## 结构模板（2000-2100字）

| 阶段 | 内容 | 字数 |
|------|------|------|
| 一 | 庶妹被禁足或表面服软，内心恨意酝酿 + 收买内线下毒 | ~300字 |
| 二 | 庶妹装弱势出场，女主冷眼旁观，双方表面对话暗藏机锋 | ~250字 |
| 三 | 茶到 → 女主喝一口即察觉（前世记忆冲击）→ 悄悄保留证据 | ~400字 |
| 四 | 找第三方（九皇子/太医）验毒，查出毒源（宫中/贵妃关联） | ~500字 |
| 五 | 男主/九皇子送解药 + 感情线微动（手上伤痕/瓶底刻字等细节） | ~350字 |
| 钩子 | 女主握药瓶，命人带上茶，明日请安/摊牌 | ~200字 |

## 核心差异点（vs 标准打脸章节）

1. **高潮不是爆发而是收敛**：标准打脸章是当场拆穿 → 证人惊呼 → 家长暴怒 → 庶妹被罚。毒计察觉章的高潮在「溯源发现贵妃关联」和「九皇子送药」——前者是剧情线扩容，后者是感情线升温。两次高潮而非一次。

2. **证据保留替代当场拆穿**：茶和帕子要收好，不打草惊蛇。女主对翠竹说"留着"即暗示后续有局。

3. **前世记忆作为唯一识别手段**：此毒"无色无味，入水即化，寻常太医根本查不出"——唯一能察觉的人是前世喝过它的人。这是重生设定的独特优势，必须利用。

4. **感情线双钩**：九皇子"采药时蹭了一下" → 女主发现瓶底刻字"小心埋伏" → 忍不住笑。这两个细节各完成一次信任软化，不可合并为一个。

## 常见错误

- **本章直接摊牌**：本章只做到"发现中毒 + 查出毒源 + 拿到解药"。摊牌反击在下章。不要急于在本章完成反击。
- **忽略贵妃线索的冲击力**：查出毒来自宫中/贵妃是本章最大反转。要给足篇幅让女主思考这意味着什么（前世以为只有顾璟和庶妹，现在发现背后还有贵妃）。
- **九皇子送药写得太公事公办**：这是重生后女主第一次对他人产生信任裂隙的章节。"半块烧饼"前世梗必须在女主内心独白中出现一次。
