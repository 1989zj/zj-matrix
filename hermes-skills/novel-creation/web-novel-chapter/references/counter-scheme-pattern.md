# 反杀设局模板 — 女频重生

**用途**: 庶妹/庶姐/姨娘使用外男+栽赃手段欲毁女主清白，被女主反杀，自食其果。

## 典型结构

### 1. 反派布局（~300字）
- 反派通过外部势力（三皇子/王府/外戚）找来执行者（外男/地痞/家丁）
- 设定诱饵：常见诱饵有"老夫人不适""兄长受伤""前院有客"
- 设定地点：后花园/废弃院落/佛堂 等僻静处
- 定下暗号：确保执行者认准人
- 关键细节：执行者不知道反派是谁，只认钱办事

### 2. 女主知悉（~200字）
- 内应传信：此前的收服（春桃/周伯/翠竹）在此刻生效
- 女主决策：不揭发、不哭闹，而是将计就计
- 关键：女主对反派的计策毫无惊讶，展现重生优势

### 3. 调换路径（~200字）
- 关键操作：灭掉某条路的灯笼、换走当事人、调换斗篷
- 常用技巧：让翠竹/心腹穿同款斗篷引开执行者
- 制造时差：反派以为女主进去了，实际进去的是反派自己

### 4. 陷阱触发（~400字）
- 执行者按时出动，抱住"目标"
- 女主方点燃信号（尖叫/灯笼/喊有贼）引众人来
- 众人到场时看到的是"二小姐被外男抱住"
- 关键：执行者说"不是你约我来的吗"——栽赃的反噬

### 5. 全场反应（~300字）
- 长辈反应：老夫人/夫人当场晕倒或暴怒
- 反派崩溃：歇斯底里喊"是沈明薇害我"，无人相信
- 围观者表情：震惊→鄙夷→暗喜（由贴身丫鬟视角描写）

### 6. 女主退场+钩子（~300字）
- 女主在暗处观看，脸上无得意之色
- 对比前世：同样的夜晚同样的场面，但主角换人
- 留下钩子：这一局只是开端，背后还有更大的势力
- 退场：转身离去，不回头，心里一片沉静

## 关键要素清单

| 要素 | 必须 | 常见变体 |
|------|------|----------|
| 内应传信 | 是 | 丫鬟/婆子/管事送来纸条或口信 |
| 斗篷/外衣调换 | 是 | 深色斗篷最好用，夜色中难辨 |
| "有贼！"尖叫 | 是 | 划破夜晚寂静，调动全府 |
| 长辈当场晕倒 | 强烈推荐 | 增加混乱感，延缓反派辩解 |
| 执行者反水说辞 | 是 | "是小姐约我来的"——定死罪名 |
| 前世对比 | 强烈推荐 | 女主看到混乱时想起自己前世的遭遇 |

## 反杀设局的三种变体

1. **标准反杀**（本章示例）：反派找执行者 → 内应传信 → 调换目标 → 反派自食其果
2. **提前截胡**：女主在反派行动前抢先布局，设假目标引反派自投
3. **延时引爆**：女主假装中计，让反派以为自己得手（1-2章后爆发，效果更狠）

## 字数分配参考（总目标2000-2100）

| 段落 | 约字数 | 说明 |
|------|--------|------|
| 开场过渡 | 200 | 上一章事件的余波，或另一条线的进展 |
| 反派布局 | 300 | 详细写反派的狠毒，让读者恨意上升 |
| 内应传信+女主决策 | 200 | 紧张感+读者获得"上帝视角"的爽感 |
| 夜晚行动 | 300 | 斗篷、灯笼、夜色、脚步声 |
| 陷阱触发+尖叫 | 400 | 高潮——执行者抱住"目标"那一刻 |
| 全场反应+长辈晕倒 | 300 | 混乱中反派崩溃 |
| 女主退场+前世对比 | 300 | 情感深度的钩子 |

## 常见错误

- **没有内应线**：读者不知道女主怎么提前知道的，会感觉强行安排
- **执行者太聪明**：外男就应该是蠢的、见钱眼开、被喝令住手时才反应过来
- **长辈反应太轻**：老夫人/夫人必须大反应——气晕、摔茶盏、喊"家门不幸"
- **写太长导致超字数**：黄昏→夜晚的行动描写容易膨胀，控制在600字以内
- **反派辩解太有效**：反派可以喊冤枉，但必须没人信——"被抓现行，说什么都是狡辩"
