# 双重身份同场戏 — 公开场合分身出招

**适用场景**：女主在同一公开场合拥有两个身份（如侯府嫡女 + 金面绣娘/神秘琴师/蒙面侠客），将信息/物品通过第二身份递出，而本人以第一身份观察效果。

## 结构模板（以2000-2100章为例）

| 时序 | 内容 | 预估字数 |
|------|------|----------|
| ① 场景搭建 | 宴会/寿宴/赛会的环境描写，重要人物点名进场 | ~300 |
| ② 场合引入 | 自然引出"神秘人物"该出现的理由（被主人邀请） | ~200 |
| ③ 身份A在场 | 女主以本人身份在场，观察局势，与关键人物互动 | ~400 |
| ④ 身份B登场 | 切换视角，金面登场，展示作品/表演 | ~500 |
| ⑤ 高潮动作 | 通过第二身份完成核心动作（递诗、送物、传话） | ~300 |
| ⑥ 身份A撤离 | 女主离席，身份B同时消失，替身/障眼法兜底 | ~300 |
| ⑦ 事后反思 | 马车/闺房中的复盘，手抖表示紧张，但信念坚定 | ~200 |

## 技法要点

### 1. 切换时机
- **不要描写换装过程**。身份A离席 → 切段落直接写身份B入场。读者自动脑补。
- 如果写换装，会破坏神秘感和节奏。记住：女主从头到尾在不同人物的视角里出现，而非在同一视角下"变装"。

### 2. 替身兜底
- 身份B离场后，必须有替身/同伙处理追查。否则身份暴露太轻易，降低智力感。
- 方案举例：相同体型的丫鬟穿相似衣物在花园露个侧影；先行准备好的另一辆马车朝相反方向驶离。
- 追查者需要至少一两个"查到的线索"——不一定是假线索，而是"这条线追下去要一个时辰，那时人已走远"的时间差。

### 3. 信息差控制
- 身份B不能知道身份A的所有计划（至少读者层面）。身份B的言行应当像真正的独立人物。
- 反过来说，身份A观察到身份B的后果后，应当有内心独白表明"那是我安排的"，但不能在场合描写中提前泄露悬念。

### 4. 双重视角的镜头语言
- 当身份B（金面绣娘）展示作品时，在描写绣品的同时穿插一句身份A（女主）的反应——不必明显，可以是"席间一位月白衣裙的闺秀掩口饮茶"这样的远景点缀。
- 高潮时刻（贵妃发现诗中藏诗），切到身份A的微观反应——手抖、呼吸一顿、抿茶——但不展开内心独白，留到事后复盘。

### 5. 事后复盘
- 女主回到私人空间后，手抖、心悸、冷汗——展现这次行动的"惊险"和"不可复制"。这让人物有温度，也为后续行动升级做铺垫。
- 复盘时要揭示：读者以为的"稳妥"实际上充满了漏洞，女主靠的是勇气+信息差，不是完美无缺。这样才显真实。

### 6. 注意事项（陷阱）
- **不要在宴会高潮处让两个身份对话或对视**。这会创造无解的逻辑漏洞。
- **身份B不能太强**。如果身份B会武功/奇术，会削弱身份A后续操纵的合理性。
- **注意时间线一致性**：身份A离席的时间和身份B登场的时间必须对得上。宴会中借口"更衣"（如厕）是最安全的选择——时间弹性大，合情合理。
- **不要过度使用**：一部长篇小说中，双重身份同场戏建议不超过3次。第二次使用时效果会减半，第三次会让读者觉得作者没招了。
