# 摊牌长辈篇 — 向家族长辈揭发阴谋

## 适用场景

在 女频重生宅斗 中，当女主掌握了庶妹/其他姨娘的罪证（毒药、人偶、书信等），选择直接向家族最高权威（老夫人/侯爷/父亲）摊牌，而不是自己动手反击时使用。与「当众打脸」的公开反杀不同，摊牌长辈的核心冲突是 **「人证物证俱在，逼权威做出裁决」**。

## 结构模板

| 节拍 | 内容 | 建议字数 |
|------|------|----------|
| 开头 | 女主前往长辈院中请安，长辈提起某事（婚事），女主打断 | ~150 |
| 取证 | 女主让丫鬟呈上物证（毒茶/人偶等），被点名的下人脸色骤变 | ~250 |
| 验证 | 长辈召府医/第三方验证，确认罪证，满堂死寂 | ~300 |
| 对峙 | 长辈震怒质问，女主平静说出作案链条和嫌疑人，下人崩溃招供 | ~350 |
| 裁决 | 长辈下令处置反派（迁出府/禁足/发卖），旁人哭嚎求饶 | ~250 |
| 独处 | 只剩祖孙二人，女主跪谢，长辈说「委屈你了」，女主内心认同：长辈有底线 | ~300 |
| 钩子 | 女主走出院门，父亲/第三方在外等候，带来新的外部威胁（宫中传召/贵妃邀请） | ~300 |

**目标总字数：2000-2100**

## 风格要点

1. **文字的氛围权重** — 摊牌篇需要营造压抑的「暴风雨前」氛围。但 **必须控制文字量**：景物描写控制在 30-50 字，重点放在人物微表情和沉默的张力上。

2. **长辈的反应弧** — 长辈从「不信/无所谓」→「开始怀疑」→「震怒」→「裁决」要有一个完整的过渡。不可直接跳到裁决。最有力量的时刻往往在沉默中（"老夫人沉默了很久"）。

3. **女主的语气** — 全程平静、恭敬、不卑不亢。这是女频「软刀子」的核心使用场景——用最恭敬的态度，说出最致命的话。切忌声泪俱下或咄咄逼人。

4. **人证的心理崩溃** — 被点名的下人（孙嬷嬷/管事婆子）需要一个「嘴硬→被铁证击穿→崩溃招供」的微过程，不能一上来就跪。

5. **女主的内心独白** — 在「独处」节拍中自然融入。通过对比前世（对长辈是否知情的不确定）和今生（确认长辈有底线），完成一次情感的沉淀。

## 字数控制警告 ⚠️

**摊牌篇是 女频段子 中最高危的过度起草场景**。原因有三：

- **三波反应需要写满**：长辈的质疑→验证过程的细节→全场的死寂氛围
- **每个节拍都自带重量**：不像毒计察觉篇可以轻描淡写地带过验证环节，摊牌篇中每种验证都要写实
- **从头到尾都在同一场景**：没有切换场景的天然断点

**真实数据（2026-05-13）**：2000-2100 字目标的摊牌篇，初稿写了 3454 字（165%）。经过 5 轮 patch 裁剪才回到 2095 字。裁剪内容主要是：
- 景物描写（从 30-50 字精简即可）
- 多人反应（姨娘们的表情不用逐个写，选 1-2 个带过）
- 证物验证过程（简化化学反应的文学描述）

**建议写法**：先写骨架（1200 字左右），再添肉（每次加 300 字检查一次），到 1800 字时必须开始收尾。
