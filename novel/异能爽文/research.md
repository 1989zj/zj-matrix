## 一、核心选题方向

### 🔥 方向一：异能觉醒 + 都市（首选）

**理由：** 番茄小说男频热榜TOP50中，"都市异能觉醒"类占比约30%-40%，是当前最稳的流量基本盘。低门槛代入——读者代入"普通人突然获得异能"的幻想，零成本、高共鸣。3万字篇幅适合快节奏：第一章觉醒+打脸，第三章小高潮，第五章小boss，节奏天然契合。

**代表对标作品：** 《我在精神病院学斩神》《我的诡异人生》《全球异能：开局觉醒SSS级》

### 🔥 方向二：异能重生 + 逆袭（备选）

**理由：** 重生叠加异能，双倍爽感。读者已知主角有前世记忆/异能等级碾压，天然制造"扮猪吃虎"空间。番茄读者对"重生弥补遗憾"题材点击率极高，适合快节奏输出满级大佬重回新手村的碾压感。

**代表对标作品：** 《重生之都市修仙》《重生之绝世武神》

### ✅ 推荐组合：**异能觉醒+都市+重生**

三合一公式：主角前世是异能之王 → 重生回觉醒当天 → 在都市中扮猪吃虎 → 碾压一切敌人。

## 五、爽点模型（8个核心爽点 × 3万字高频布局）

### 爽点清单

| 编号 | 爽点类型 | 说明 | 3万字内布局策略 |
|------|---------|------|----------------|
| 1 | **打脸** | 反派看不起主角→主角反杀打脸 | 每章至少1次。第1章：同学/前女友打脸；第3章：老师/上司打脸；第5章：家族/势力打脸 |
| 2 | **逆袭** | 从底层/废物→碾压全场 | 第1章完成身份反转（觉醒）；第2章小范围逆袭；第5章大规模逆袭 |
| 3 | **碾压/降维打击** | 同级觉得很强，主角随手秒 | 第3章、第6章、第8章各安排一次，展示等级差带来的绝对碾压 |
| 4 | **扮猪吃虎** | 主角隐藏实力→对方轻敌→反杀 | 全篇贯穿。第2章隐藏实力被嘲笑；第4章被迫展露部分实力；第7章全暴露 |
| 5 | **装逼打脸** | 主角低调说出惊人真相 | 每2章一次。如："这个SSS级异能……其实是我最弱的一个" |
| 6 | **震惊全场** | 围观群众的震惊反应 | 每次碾压/打脸/装逼后，必须有一段"围观群众震惊"的描写 |
| 7 | **收获/奖励** | 击败敌人后获得新能力/宝物/美女认可 | 每章末尾留钩子：击败小怪得到稀有道具；击败boss得到核心升级 |
| 8 | **复仇/清算** | 前世/过去的仇人一个个被踩 | 第2章清算第一个小仇人；第5章清算中层仇人；第8章引出终极仇人 |
| 9 | **#额外#异能进化** | 异能从低到高不断升级，视觉化展示 | 第1章觉醒F级；第3章升到D级；第5章C级；第7章B级……每升一级绑定一次打脸 |
| 10 | **#额外#美女倾倒** | 高冷女神/女强人对主角另眼相看 | 第2章初遇+嫌弃；第4章改观；第6章倾心；第8章修罗场 |

### 3万字节奏规划（约12-15章）

```
第1章（2000字） ：被羞辱/被抛弃 → 觉醒最强异能 → 当场打脸 → 钩子：有人盯上主角
第2章（2000字） ：扮猪吃虎 → 隐藏实力去学校/公司 → 小冲突 → 收获第一个跟班/道具
第3章（2500字） ：第一个小boss出现 → 碾压式击败 → 围观群众震惊 → 获得第一次升级
第4章（2500字） ：女主/重要角色出场 → 主角低调救场 → 美女好感度+1
第5章（2500字） ：家族/势力矛盾激化 → 主角展露部分实力 → 中等boss被秒
第6章（2500字） ：异能升级 → 新能力展示 → 又一个反派被打脸
第7章（2500字） ：前世仇人出现 → 复仇清算 → 引爆情绪
第8章（2500字） ：大型冲突（势力战/副本）→ 主角全实力曝光 → 全场震惊
第9章（2500字） ：战后收获 → 新能力+新势力拉拢 → 再遭暗算
第10章（2500字）：高层关注 → 主角进入更大舞台 → 钩子：更强的敌人
第11章（2000字）：过渡+日常+感情线升温 → 危机预兆
第12章（2000字）：boss战前奏 → 女主遇险 → 主角爆发
第13章（3000字）：最终战（3万字大结局）→ 全面碾压 → 新的征程开启
```

**核心原则：** 每500字至少一个小爽点，每2000字一个中型高潮，每5000字一个大型爆点。全程无尿点，读者舍不得划走。

## 六、风险提示（番茄审核敏感词规避）

### 🚫 绝对禁止（直接封书）

| 类别 | 示例 | 替代方案 |
|------|------|---------|
| 真实政治人物 | 主席、总理、习近平 | 虚构职务：总长、执政官 |
| 敏感历史事件 | 文革、六四、建国前秘史 | 完全不提 |
| 国家机构名称 | 国安局、公安部、中央军委 | 国家特勤局、安全部、武道协会 |
| 色情露骨描写 | 性器官、具体性行为 | 拉灯处理、暧昧暗示（吻到即可） |
| 现实宗教诋毁 | 伊斯兰、佛教负面 | 虚构宗教或境外邪教 |
| 毒品详细描写 | 制毒步骤、吸毒体验 | 可以在涉毒反面描写但不要细节 |
| 自杀详细方法 | 割腕步骤、跳楼过程 | 建议：发现时已死或轻描淡写 |

### ⚠️ 高度敏感（会被限流/整改）

| 类别 | 示例 | 替代方案 |
|------|------|---------|
| 血腥暴力过度 | 碎尸、凌迟详细描写 | "场面极其惨烈"一笔带过 |
| 校园霸凌细致描写 | 校园暴力详细步骤 | 三言两语暗示即可 |
| 真名辱骂名人 | 带名字的负面评价 | 用谐音或虚构名 |
| 涉军敏感 | 军队叛乱、军人负面 | 改为"特勤部队"等虚构机构 |
| 践踏法律底线 | 主角杀人不偿命 | 设定异能有特殊执法权/异人世界自有规则 |
| 未成年色情 | 16岁以下角色恋爱描写 | 主角设为18岁以上或大学背景 |
| 过度崇洋媚外 | 外国碾压中国、丑化国人 | 平衡描写或设定在虚构国家 |

### ✅ 推荐安全设定

1. **世界观隔离法**：设定"异能者世界独立于普通人世界"，异能战斗不影响现实法律
2. **机构虚构法**：所有国家机构改为"异能管理局""超凡议会""武道联盟"
3. **年龄上移法**：主角设定18-22岁，避开未成年红线
4. **战斗抽象法**：异能战斗用"能量冲击""光芒爆发"等抽象词汇，少写血肉横飞
5. **感情节制法**：暧昧可以有，明确关系留到完本/番外，不写擦边
6. **反派洗白法**：反派的恶行不要涉及现实中的恶性犯罪（强奸、贩毒等），避免审核联想
